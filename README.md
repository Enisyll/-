# 🐍 PyQuest: путь Claude

Пиксельная игра для изучения **Python с нуля до уверенного кодера**. Claude идёт по дороге через 7 миров, а ты на каждой остановке изучаешь тему и решаешь задания. Код выполняется **настоящим Python** прямо в браузере (Pyodide).

## Что внутри
- **50 уроков в 7 мирах**: Зелёная долина (основы) → Строковый лес → Пустыня условий → Ледяные пещеры (циклы) → Горы коллекций → Замок функций → Вулкан мастера (исключения, модули, ООП, файлы, финальный босс).
- **По 5 заданий на каждую тему** (всего 250), чтобы синтаксис запомнился: `.upper()`, `.strip()`, `.split()`, `.join()`, срезы, `range()`, словари, `lambda` и т.д.
- **Повторение** (кнопка ↻): случайная тренировка, «Слабые места» (задачи с ошибками или подсмотренным решением), последние темы, повтор любого пройденного урока и шпаргалки с теорией.
- Подсказки 💡, решения 👁 (стоят звезду), понятные объяснения ошибок на русском, защита от бесконечных циклов.
- Звёзды, опыт, уровни, серия дней, 8-битные звуки.
- **Песочница** `{}`: пиши любой код.
- Редактор с подсветкой, автоотступами и панелью символов для телефона.
- Перенос прогресса между ПК и iPhone кодом (⚙ → «Перенос прогресса»).

## Как запустить

### На ПК
Нужен браузер (Chrome, Edge, Firefox, Safari). Запусти локальный сервер в папке проекта:
```bash
python3 -m http.server 8000
```
и открой http://localhost:8000. Можно открыть и сам `index.html` двойным щелчком, но офлайн-режим работает только через сервер.

### На iPhone / iPad
1. Выложи игру на любой статический хостинг. Проще всего — GitHub Pages: *Settings → Pages → Deploy from a branch → `main` / `(root)`*. Игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.
2. Открой ссылку в **Safari** → «Поделиться» ⬆ → **«На экран „Домой“»**.
3. Игра запускается во весь экран, как приложение. После первой загрузки (~13 МБ — сам Python) она работает и без интернета.

## Структура
```
index.html          — интерфейс и стили
js/game.js          — движок: карта, редактор, проверка, повторение
js/w0.js … w6.js    — уроки (теория + 5 заданий на урок)
sw.js               — офлайн-кэш (service worker)
manifest.webmanifest, icons/ — установка как приложение
tools/              — проверка всех эталонных решений
```

## Как добавить урок
Добавь объект в массив `lessons` нужного мира (`js/wN.js`):
```js
{ id: "unique_id", title: "Название", theory: `<p>HTML с теорией</p><pre>код</pre>`,
  ex: [ { t: "Текст задания", s: "стартовый код", e: "ожидаемый вывод",
          m: [".upper()"],      // что обязательно должно быть в коде ("re:" — регулярное выражение)
          i: ["ввод"],          // необязательно: значения для input()
          test: "assert f(2) == 4",  // необязательно: скрытая проверка
          sol: "решение", h: "подсказка" }, /* ×5 */ ] }
```
Проверка, что все решения проходят:
```bash
node tools/dump.js > /tmp/w.json && python3 tools/check_solutions.py /tmp/w.json
```
